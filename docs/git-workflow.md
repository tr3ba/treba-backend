# Git Workflow

Основна гілка:

main

Для роботи використовуються окремі гілки:

feature/*
fix/*
migrate/*

Приклад:

feature/stage3-tests
feature/stage3-security-scan
feature/stage3-release-workflow

Робочий процес:

main
feature branch
commit
push
Pull Request
CI checks
review
merge

Зміни перевіряються через GitHub Actions.

Для merge використовується Pull Request і review.
