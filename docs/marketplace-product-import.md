# Импорт товаров по ссылке

Продавец открывает «Импорт» в Telegram Mini App, вставляет HTTPS-ссылку на конкретный товар и проверяет предпросмотр. Создание предпросмотра ничего не публикует. Цена, остаток, магазин, бренд и обязательные характеристики проверяются перед отправкой модератору.

## Источники

- **Rozetka:** публичный API `product-api.rozetka.com.ua/v4/goods/get-main`, затем `get-characteristic`. Если основной API недоступен, загрузчик пробует публичную HTML-страницу. Проверяется соответствие ID товара исходной ссылке. Если полное описание отсутствует в ответе источника, используется доступное краткое описание и характеристики.
- **Prom.ua:** страницы `/ua/p123456-name.html` и `/p123456-name.html`, включая магазины на поддоменах `prom.ua`. Читаются JSON-LD Product, breadcrumbs, полный блок описания и таблицы характеристик.
- **Эпицентр:** страницы `/ua/shop/name.html` и `/shop/name.html`. Читаются JSON-LD, серверный HTML и JSON с данными товара внутри `dataLayer.push`; JavaScript источника не исполняется. Поддерживаются фото из `cdn.27.ua` и `cdn.epicentrk.ua`.

Фотографии ограничены восемью файлами до пяти МБ каждый. Импортируется содержимое, доступное в ответе источника; скрытые данные и отсутствующие изображения не дополняются выдуманными значениями. Загрузка зависит от доступности маркетплейса. CAPTCHA и авторизация источника не обходятся. Это импорт отдельных карточек по ссылке, а не массовое копирование каталога и не синхронизация остатков.

## Категории и доступ

Существующее сопоставление категории источника с категорией Treba имеет приоритет. Продавец не может подменить его другой категорией.

Продавец с доступом **ко всем текущим активным категориям** может классифицировать ещё не сопоставленный товар: сначала ищется единственное точное совпадение названия категории без учёта регистра и пунктуации; если совпадения нет, продавец выбирает категорию Treba под полем ссылки. Это решение сохраняется только в предпросмотре. Оно не меняет глобальные сопоставления и требует модерации товара.

Для продавцов с ограниченными разрешениями несопоставленная категория по-прежнему блокируется до настройки администратором. При отправке заново проверяются доступ продавца, категория, действующее сопоставление и принадлежность активного магазина. Если доступ к полному каталогу отозван, ранее классифицированный предпросмотр отправить нельзя.

Коды Rozetka сохраняют формат `c123456`. Для других источников используются отдельные ключи `prom:<12 hex>` и `epic:<12 hex>`; их можно сопоставить через `PUT /api/v1/admin/telegram/mappings`. В предпросмотре префикс `u:` обозначает классификацию продавцом с полным доступом. Все ключи укладываются в существующие ограничения таблиц, миграция не требуется. Идентификаторы товаров разных маркетплейсов также разделены; прежние ID Rozetka сохранены.

Разрешение на родительскую категорию с подкатегориями покрывает новые подкатегории этой ветки. Новые корневые категории нужно разрешать отдельно. Неактивные категории и категории с неактивными предками недоступны.

## Проверка

```powershell
dotnet test src/Rozetka-clone/WebApi.Tests/WebApi.Tests.csproj -c Release
```

Проверяются источники и URL, чтение API Rozetka и HTML других маркетплейсов, запрет непубличных адресов и внешних перенаправлений, отдельные ID товаров, классификация неизвестных категорий и повторная проверка прав перед отправкой. Формат стандартных данных товара: [Schema.org Product](https://schema.org/Product).
