# Сравнение каталога Treba с Rozetka

Срез от 21 октября 2026 года. Источник: [все категории Rozetka](https://rozetka.com.ua/ua/all-categories-goods/), публичный API `https://common-api.rozetka.com.ua/v1/api/categories/all?lang=ua&country=UA`.

| Показатель | Количество |
| --- | ---: |
| Категории Treba до обновления | 508 |
| Уникальные категории в публичном справочнике Rozetka | 4 632 |
| Сопоставлены с существующими категориями Treba | 202 |
| Добавляются новые категории | 4 430 |
| Ожидаемый итоговый каталог Treba | 4 938 |
| Категории с собственной картинкой или примером товара из раздела | 4 630 |
| Категории без фото, использующие фото родительского раздела | 2 |

Дополнительные группировки Treba сохраняются. Существующие идентификаторы, slug, родители, товары, отключённые категории и пользовательские изображения не удаляются. Название сопоставленной категории обновляется только если оно совпадает с исходным названием из проверенного среза Treba. Уже заданные администратором сопоставления источника имеют приоритет.

Полный снимок хранится в `src/Rozetka-clone/WebApi/CatalogData/rozetka-categories.json`. Каждая запись содержит ключ источника, родительский ключ, название, исходную ссылку, сопоставление с прежним slug и происхождение изображения. Ссылки на картинки не содержат рекламных фрагментов. Все уникальные HTTPS-изображения снимка проверены: HTTP 200 и тип `image/*`. Фотографии остаются на CDN Rozetka.

Обновление выполняет штатная команда публикации `--migrate-admin-operations`: транзакция, блокировка от одновременного запуска, повторяемое добавление категорий и сопоставлений. Продавцы с доступом ко всему прежнему каталогу сохраняют полный доступ, включая новые ветви. Ограниченные продавцы получают только наследование ранее выданных разрешений.

Сами товары, цены, остатки и бренды из Rozetka не импортируются. Фотографии товаров в админке берутся из уже сохранённых карточек. Старые группировки путешествий и акций получают близкие по смыслу изображения; администратор может заменить их в редакторе категории.

Для воспроизводимого сбора без записи в базу:

```powershell
py scripts/catalog/collect-rozetka-catalog.py --cache .treba-local/rozetka-catalog
py scripts/catalog/build-rozetka-snapshot.py --cache .treba-local/rozetka-catalog --treba-tree .treba-local/published-category-tree.json --output src/Rozetka-clone/WebApi/CatalogData/rozetka-categories.json
```

Сбор использует четыре ограниченных потока, сохраняет кэш и прекращает новые запросы при ответе 429. Перед публикацией новый снимок нужно проверить и закоммитить; пользовательские запросы не запускают сбор каталога с внешнего сайта.
